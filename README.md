# Football Scout AI

Personal portfolio project: find **statistically similar** football players from [StatsBomb Open Data](https://github.com/statsbomb/open-data) and explore possible transfer candidates.

This is a **learning project**, not a production recruitment tool. Similarity scores are a starting point for exploration. They do **not** prove that a player is a good transfer.

## MVP

Python + pandas features (per-90, position-aware) → simple **scikit-learn** similarity ranking → **Streamlit** UI.
